# Sarah Studio — сайт продакшн-студии

Многостраничный статический сайт (HTML + CSS + JS, без сборки) на трёх языках:
**English / Русский / Қазақша** — переключатель EN · RU · KZ в шапке.

Страницы: `index` (главная), `work` (портфолио + фильтр), `project.html?p=<slug>`,
`about`, `equipment`, `team`, `reviews`, `contact`.

## Запуск
```
cd sarah-studio
python -m http.server 5173
```
Откройте http://localhost:5173. Язык можно задать ссылкой: `?lang=en|ru|kk`.

## Где что менять
| Что | Файл |
|---|---|
| Тексты интерфейса (3 языка) | `assets/js/i18n.js` |
| Проекты, команда, отзывы, награды, оборудование, клиенты | `assets/js/data.js` |
| Цвета, шрифты, вёрстка | `assets/css/style.css` (переменные в `:root`) |

## Медиа
Сейчас вместо видео и фото — типографские постеры и плейсхолдеры в фирменных цветах.
Чтобы подключить реальные материалы:
- шоурил: `assets/video/showreel.mp4` (грузится только после загрузки страницы, без звука, в цикле);
- превью проектов при наведении: `assets/video/<slug>.mp4` (поле `video` в `data.js`);
- кадры проекта: добавьте `stills: ["assets/img/..jpg", ...]`;
- фото команды: добавьте `photo: "assets/img/..jpg"` (ч/б по умолчанию, цвет при наведении).

## Важно перед запуском в прод
Все проекты, клиенты, отзывы, награды и публикации в прессе — **вымышленные
примеры**. Замените их реальными. Телефон `+44 20 7946 0123` — из тестового
диапазона Ofcom. Форма контактов открывает почтовый клиент (mailto),
подписка на рассылку только показывает сообщение — подключите Formspree /
Mailchimp или свой бэкенд. Домен в canonical/hreflang — GitHub Pages этого репозитория.
