# Менеджер паролей

Веб-приложение (PWA) для хранения логинов и паролей. Всё шифруется **в браузере**
(AES-256-GCM, ключ из мастер-пароля через PBKDF2-SHA-256, 600 000 итераций,
уникальная соль на пользователя). Сервер (Supabase) получает только шифртекст.
Помнить нужно один мастер-пароль.

Ссылка после публикации на GitHub Pages:
**https://kartabaykairat-svg.github.io/ent-trainer/passwords/**

- Исходники: эта папка (`password-manager/`, React + TypeScript + Tailwind CSS + Vite).
- Готовая сборка: папка [`../passwords/`](../passwords) — именно её открывает GitHub Pages.

## Как устроена безопасность

| Что | Как |
|---|---|
| Шифрование | AES-256-GCM (Web Crypto API), новый случайный IV на каждое сохранение. Шифртекст привязан к пользователю и записи (AAD), его нельзя «подменить» другой строкой из базы. |
| Ключ | PBKDF2-SHA-256, 600 000 итераций, 16-байтная случайная соль на пользователя. Ключ — non-extractable `CryptoKey`, живёт только в памяти. |
| Zero-knowledge | Мастер-пароль и ключ никуда не отправляются и не пишутся в localStorage. На сервере зашифровано всё: сервис, логин, пароль, ссылка, заметка, категория, история. |
| Проверка мастер-пароля | По проверочному шифртексту: AES-GCM не расшифрует его чужим ключом. |
| RLS | Каждая таблица под Row Level Security: пользователь видит только свои строки. Если включена 2FA, данные отдаются только после ввода кода (уровень `aal2`). |
| Автоблокировка | После 1 / 5 / 15 / 30 минут бездействия и при закрытии вкладки ключ и расшифрованные данные стираются из памяти. Горячая клавиша: Ctrl+Shift+L. |
| Буфер обмена | Скопированный пароль стирается через 30 секунд (если в буфере всё ещё он). |
| Попытки | После 5 неверных мастер-паролей — пауза 30 с, дальше удваивается (1 мин, 2 мин…, максимум 1 час). |
| Прочее | Строгая Content-Security-Policy, `no-referrer`, никаких `console.log`, аналитики и секретов в URL. Генерация — только `crypto.getRandomValues`. |

> Ограничение попыток работает в браузере. Настоящая защита от перебора — это
> сам мастер-пароль и 600 000 итераций PBKDF2, поэтому приложение требует
> мастер-пароль не короче 10 символов и не «слабый».

## Настройка Supabase (один раз, ~10 минут)

1. Откройте проект на <https://supabase.com> (можно тот же, что для «Семейного
   бюджета» — таблицы менеджера паролей называются `pm_*` и не пересекаются).
2. **SQL Editor → New query** → вставьте весь файл [`schema.sql`](./schema.sql) → **Run**.
   Скрипт можно запускать повторно.
3. **Authentication → URL Configuration**:
   - *Site URL*: `https://kartabaykairat-svg.github.io/ent-trainer/passwords/`
   - *Redirect URLs*: добавьте тот же адрес (нужен для писем подтверждения и сброса пароля).
4. **Authentication → Sign In / Providers → Email**: оставьте включённым. «Confirm email»
   можно оставить включённым — тогда после регистрации придёт письмо.
5. **Authentication → Multi-Factor**: убедитесь, что TOTP включён (по умолчанию включён).
6. Ключи подключения лежат в [`public/config.js`](./public/config.js) и в готовой
   сборке [`../passwords/config.js`](../passwords/config.js). Сейчас там адрес того же
   проекта, что у «Бюджета». Чтобы подключить другой проект, поменяйте `supabaseUrl` и
   `supabaseAnonKey` в **обоих** файлах (пересобирать не нужно). Ключ *anon* публичный.

Если оставить ключи пустыми, приложение работает в **локальном режиме**: без аккаунта,
зашифрованные данные хранятся только в этом браузере (удобно для проверки).

## Разработка

```bash
cd password-manager
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в ../passwords
```

После изменений в коде выполните `npm run build` и закоммитьте папку `passwords/`.

## Экраны

1. Вход / регистрация (+ сброс пароля аккаунта)
2. Код 2FA (если включена)
3. Создание мастер-пароля: индикатор надёжности и предупреждение «Если забудете мастер-пароль, восстановить данные невозможно»
4. Разблокировка хранилища
5. Пароли: поиск, категории, сортировка, избранное, буквы-разделители и быстрый переход по букве; на десктопе детали справа, на телефоне — отдельный экран
6. Добавление / редактирование записи (блок «Ещё»: категория, заметка, избранное); предупреждение о дубликате; история 5 последних паролей
7. Генератор: 8–64 символа, наборы символов, исключение похожих, запоминаемая фраза (список слов EFF), надёжность в реальном времени
8. Аудит: оценка 0–100, слабые, повторяющиеся, старше 180 дней, утечки через HaveIBeenPwned (k-anonymity)
9. Настройки: автоблокировка, тема, свои категории, смена мастер-пароля с перешифровкой, 2FA, журнал входов, импорт/экспорт, установка на телефон, выход, удаление аккаунта

## Как проверить

**Этап 1 — MVP**
1. Зарегистрируйтесь, подтвердите email, войдите.
2. Создайте мастер-пароль (слабый не примет; без галочки-предупреждения тоже).
3. «+ Добавить» → Instagram / логин / «Сгенерировать» → Сохранить. Запись сразу в списке, форма очищена.
4. Добавьте ту же пару «сервис + логин» ещё раз — появится «Такая запись уже есть → Обновить пароль». В деталях записи появится «История паролей».
5. Поиск, вкладки категорий, «+ Своя» категория, переключатель «А–Я / Новые / Недавние», буквы справа.
6. В Supabase → Table Editor → `pm_entries`: в колонке `data` только `v1:…` (шифртекст).
7. Подождите 1 минуту бездействия (Настройки → 1 мин) или закройте вкладку — хранилище заблокировано.
8. Введите неверный мастер-пароль 5 раз — появится пауза.

**Этап 2 — расширения**
1. Аудит: слабые/повторы видны сразу; «Проверить утечки» (например, пароль `123456` найдётся).
2. Настройки → Импорт: CSV из Chrome (`chrome://password-manager/settings` → Экспорт), Bitwarden или LastPass.
3. Экспорт: зашифрованный JSON (с отдельным паролем) — его можно импортировать обратно; CSV — только после предупреждения и ввода мастер-пароля.
4. Смена мастер-пароля: после неё старый не подходит, все записи на месте.
5. 2FA: «Включить 2FA» → QR → код. Выйдите и войдите — попросит код.
6. Журнал входов: дата, браузер и система, IP.
7. PWA: «Установить» (Android/Chrome) или «Поделиться → На экран Домой» (iPhone). Без сети приложение открывается и показывает последнюю сохранённую зашифрованную копию (только просмотр).
