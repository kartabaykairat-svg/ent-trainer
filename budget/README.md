# Семейный бюджет

Веб-приложение для семьи, копия таблицы из Excel. Открывается по одной ссылке
с любого телефона или компьютера. Все вводят и меняют данные, остальные видят
изменения сразу.

## Экраны

| Экран | Что там |
|---|---|
| **Таблица** | Месяц как в Excel: строки прихода, колонки расходов, остаток, итого, «оплачено», «осталось оплатить», отметки оплаты цветом, «Скачать в Excel». |
| **Долги** | Кому сколько должны, платёж в месяц (из колонок «Долг …»), остаток, за сколько месяцев погасим. |
| **Акмарал** | Калькулятор: ставка на долг с каждого платежа клиента, куда идут деньги, сравнение двух ставок. |
| **Итог** | Получено, оплачено, деньги на руках, осталось оплатить, хватит ли, удержано на Халык. |
| **Ещё** | Участники и PIN-коды, процент халыка, история изменений с кнопкой «Вернуть». |

Без настройки приложение работает в **демо-режиме**: данные хранятся только
на одном устройстве. Чтобы вся семья работала с одними данными, один раз
подключите бесплатную базу Supabase (около 10 минут).

## Шаг 1. Создать бесплатную базу Supabase

1. Зайдите на <https://supabase.com>, нажмите **Start your project** и войдите
   (через GitHub или почту). Тариф **Free** — бесплатно.
2. **New project** → придумайте название (например `budget`) и пароль
   базы (его можно забыть, приложению он не нужен) → регион поближе
   (например *Central EU (Frankfurt)*) → **Create new project**. Подождите 1–2 минуты.
3. Слева откройте **SQL Editor** → **New query**. Скопируйте туда весь текст
   из файла [`schema.sql`](./schema.sql) и нажмите **Run**. Должно появиться
   «Success».
4. Слева откройте **Project Settings → API** (или **Data API / API Keys**).
   Скопируйте два значения:
   - **Project URL** (вида `https://abcd1234.supabase.co`);
   - **anon public** key (длинная строка, начинается с `eyJ…`).

## Шаг 2. Вписать ключи в приложение

Откройте файл [`config.js`](./config.js) (на GitHub: файл → значок ✏️) и
вставьте значения:

```js
window.BUDGET_CONFIG = {
  supabaseUrl: 'https://abcd1234.supabase.co',
  supabaseAnonKey: 'eyJ...ваш ключ...',
};
```

Сохраните (**Commit changes**). Ключ *anon* можно хранить в открытом виде,
он для этого и сделан.

## Шаг 3. Открыть приложение по ссылке

Приложение лежит на GitHub Pages вместе с остальными файлами репозитория.
После того как изменения попадут в ветку `main`, ссылка будет такой:

**https://kartabaykairat-svg.github.io/ent-trainer/budget/**

Если ссылка не открывается: на GitHub в репозитории откройте **Settings →
Pages** и проверьте, что выбрано *Deploy from a branch*, ветка `main`,
папка `/ (root)`. Обновление сайта занимает 1–2 минуты.

## Шаг 4. Отправить семье

1. Откройте ссылку сами. При первом входе введите своё имя и придумайте
   PIN-код. Начальные данные за октябрь и ноябрь появятся сами.
2. Откройте **Ещё → Участники → Добавить участника**, впишите имя члена семьи
   и PIN.
3. Отправьте ссылку в WhatsApp или Telegram и скажите PIN. Человек
   открывает ссылку, нажимает на своё имя и вводит PIN.
4. Установите приложение на главный экран. Появится иконка «Бюджет»,
   и приложение будет открываться без адресной строки, как обычное:
   - Android (Chrome): над таблицей появится кнопка «Установить», или
     меню ⋮ → «Установить приложение»;
   - iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
   Подсказка есть и в приложении: «Ещё → Установить на телефон».

## Как пользоваться

- **Сумма и отметка оплаты**: нажмите на ячейку. Жёлтый — оплачено,
  красный — не оплачено, фиолетовый — частично (спросит, сколько уже оплачено).
  Цветом закрашиваются только Музыкалка, Англ. Медина, Колледж Лулуа,
  Колледж Батый, Кредит Батый. В остальных колонках отметка видна точкой в углу.
- **Приход**: нажмите на название строки. Фактический приход считается сам
  (приход − халык). Если вписать его вручную, он отмечается синей точкой.
  Чтобы снова считалось само, сотрите значение.
- **Новая строка**: нажмите «＋ строка». Акмарал всегда остаётся последней строкой.
- **Название колонки**: нажмите на заголовок.
- **Новый месяц**: копирует строки, колонки и суммы предыдущего месяца,
  отметки оплаты начинаются заново.
- **Кто и когда менял**: показано над таблицей и внизу окна ячейки. Полная
  история с кнопкой «Вернуть» — в разделе «Ещё».
- **Без интернета** видны последние загруженные данные, но изменения не
  сохраняются. Приложение об этом предупредит.

## Файлы

- `index.html`, `styles.css`, `app.js` — приложение;
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на главный экран и запуск без интернета;
- `config.js` — ключи Supabase;
- `schema.sql` — таблицы для Supabase;
- `vendor/` — библиотеки Supabase и ExcelJS (лежат в репозитории, чтобы не
  зависеть от сторонних сайтов).

Вход по имени и PIN — простая защита для семьи. Кто знает ссылку и ключ,
технически может прочитать данные из базы. Не храните здесь пароли и номера карт.
