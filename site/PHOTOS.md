# Фото для сайта «Мир Языков»

Этот сайт (`site/index.html` — главная со слайдером, `site/about.html` —
страница «Обо мне») сейчас использует **сгенерированные SVG-плейсхолдеры**
вместо настоящих фотографий: в этой сессии нет инструмента генерации
изображений, поэтому вместо реальных снимков лежат тёплые/элегантные
цветные заглушки с иконкой, подписью и водяным знаком «ФОТО — ЗАМЕНИТЬ».
Каждый плейсхолдер уже хранит полный промпт в `<title>`/`<desc>` самого
SVG-файла (можно открыть файл в текстовом редакторе и увидеть промпт),
а также продублирован в таблице ниже.

Верстка, слайдер, параллакс и адаптив уже готовы — чтобы поставить
настоящие фото, достаточно **заменить `src` у `<img>`** на реальный файл
(см. «Как заменить» ниже). Ничего в разметке менять не нужно.

## Как заменить плейсхолдер на реальное фото

1. Сгенерируйте/подберите фото по промпту из таблицы (референс стиля —
   Sam Youkilis: тёплый золотой свет, лёгкая зернистость, «подсмотренный»,
   а не постановочный кадр).
2. Экспортируйте в **WebP** (быстрая загрузка) — при необходимости
   подготовьте два кадрирования:
   - горизонтальное — для десктопа;
   - **вертикальное** — для мобильной версии (на мобильном в слайдере
     сейчас показывается только одно, самое крупное фото на весь экран —
     см. `@media (max-width: 720px)` в `assets/css/site.css`, поэтому
     вертикальный кроп большого фото особенно важен).
3. Положите файл в `site/assets/img/photos/` (создайте папку) и замените
   `src="./assets/img/placeholders/xxx.svg"` на
   `src="./assets/img/photos/xxx.webp"` в `index.html` / `about.html`.
4. Не убирайте атрибут `loading="lazy"` у фото, которые не видны сразу
   при загрузке страницы (всё, кроме первого большого фото слайда и
   портрета на «Обо мне» — они специально помечены `fetchpriority="high"`
   и без `lazy`, чтобы не тормозить первую отрисовку).
5. Для действительно раздельного кропа десктоп/мобайл замените `<img>`
   на `<picture>` с `<source media="(max-width: 720px)" srcset="...-mobile.webp">`
   — сам тег `<picture>` в разметке уже подготовлен вокруг большого фото
   каждого слайда.

## Технические решения, уже заложенные в вёрстку

- **Формат** — макет рассчитан на WebP (плейсхолдеры временно в SVG).
- **Lazy-load** — все фото, кроме первого экрана, помечены `loading="lazy"`.
- **Параллакс** — лёгкое смещение коллажа фото при скролле
  (`assets/js/slider.js`), отключается при `prefers-reduced-motion`.
- **Автопереключение слайдов** — каждые 5.8 сек, плавный cross-dissolve
  через CSS `opacity`-переход (1.15 с), пауза при наведении/фокусе.
- **Мобильная адаптация** — на экранах ≤720px слайдер показывает только
  одно крупное фото на слайд с вертикальным кадрированием
  (`object-fit: cover`) вместо коллажа из 4 фото.
