# gen-automation — ночная очередь генераций (Playwright)

```
pip install -r requirements.txt && playwright install chromium
# 1) впишите url и селекторы в config.json
python run.py --login   # один раз: залогиниться в открывшемся браузере
# 2) положите промпты в prompts.txt (по одному на строку)
python run.py           # запуск; при падении просто запустите снова — продолжит
```

Перед каждой генерацией проверяются `pre_checks` (Unlimited, разрешение,
число параллельных). Не совпало — скрипт останавливается и пишет в `run.log`.
Результаты и скриншоты ошибок — в `output/`. Запускать на своём компьютере,
не в облаке (нужен ваш логин и обычный IP).

## Быстрая настройка кликами
`python record.py https://адрес-страницы-генерации` — залогиньтесь, затем кликайте
на элементы по подсказкам в консоли; `config.json` заполнится сам.
