# Test di livello d'italiano (A1–B2)

Веб-приложение для определения уровня владения итальянским языком (A1, A2, B1, B2)
через последовательный адаптивный тест.

## Запуск

Приложение состоит только из статических файлов (HTML/CSS/JS, без сборки и зависимостей),
поэтому его можно открыть прямо из файловой системы:

```
italian-test/index.html
```

Либо запустить через локальный сервер (например, если браузер ограничивает работу
скриптов при открытии файла напрямую):

```
cd italian-test
python -m http.server 5173
```

и открыть `http://localhost:5173`.

## Как устроен тест

- **40 вопросов**, по 10 на каждый уровень: A1 → A2 → B1 → B2, от простого к сложному.
- **Один вопрос на экран**, сверху — прогресс-бар и индикатор текущего уровня.
- **Адаптивная остановка**: если пользователь допускает 3 ошибки подряд, тест
  останавливается и засчитывается предыдущий пройденный уровень (или «ниже A1»,
  если ошибки допущены уже на A1).
- **Типы заданий** (чередуются): выбор одного варианта из четырёх, заполнение
  пропуска, понимание текста (B1–B2), соответствие слово—перевод (A1–A2),
  выбор правильной формы глагола.
- **Языки интерфейса**: русский и английский (переключаются на старте и во
  время теста; сами тестовые задания — на итальянском, как и положено для
  языкового теста).
- По окончании показывается **итоговый уровень**, результаты по каждому
  пройденному уровню и **рекомендации** для дальнейшего изучения.

## Структура

```
italian-test/
├── index.html          # разметка трёх экранов: старт / тест / результат
├── src/
│   ├── data.js         # вопросы (40 шт.), UI-строки (ru/en), рекомендации
│   ├── app.js          # логика теста: рендер, адаптивная остановка, подсчёт уровня
│   └── styles.css       # стили
└── README.md
```

## Добавление или изменение вопросов

Вопросы лежат в массиве `QUESTIONS` в `src/data.js`. Общий вид объекта:

```js
{
  id: "q1",
  level: "A1",                 // A1 | A2 | B1 | B2
  type: "choice",               // choice | fill | reading | match | conjugate
  topic: { ru: "...", en: "..." },
  question: "Testo della domanda ___.",
  passage: "Текст для чтения (только для type: reading)",
  options: ["opzione 1", "opzione 2", "opzione 3", "opzione 4"],
  answerIndex: 0,
}
```

Для вопросов на перевод значения слова опции можно задавать как объект
`{ ru: "...", en: "..." }` — тогда они локализуются под выбранный язык
интерфейса. Для типа `match` вместо `options`/`answerIndex` используется
`pairs: [{ it, ru, en }, ...]`.

Порядок вопросов в массиве и есть порядок их показа, поэтому первые 10 должны
быть уровня A1, следующие 10 — A2, и так далее.
