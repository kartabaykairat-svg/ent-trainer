# Лендинг Бибигуль — AI-видео и фото

Одностраничный лендинг для AI-контент-мейкера Бибигуль (@ai.video.kz).

## Запуск
Просто откройте `index.html` в браузере, либо через локальный сервер:

```
cd bibigul-landing
python -m http.server 5174
```
Затем откройте `http://localhost:5174`.

## Что внутри
Один файл `index.html` — вся вёрстка, стили и анимации (без сборки, без зависимостей).

Разделы: Hero → Услуги → Портфолио (плейсхолдеры) → Цены (3 тарифа-заглушки) → Контакты → Футер.

## Что нужно донастроить
- В блоке «Цены» (`#pricing`) заменить `от ___ ₸` на реальные суммы.
- В блоке «Портфолио» (`#portfolio`) заменить плейсхолдеры на реальные фото/видео примеры работ.
- Контакты (WhatsApp `+7 702 371 23 99` и Instagram `@ai.video.kz`) уже подключены рабочими ссылками.
